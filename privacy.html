Privacy Policy

Last Updated: October 16, 2026

Overview

Fix My Photo Dates is a Windows desktop application. This policy describes the app and this GitHub Pages website. Refer to the Microsoft Store listing for current pricing and licensing information.

Data Collection

The desktop application collects NO data. All processing happens locally on your computer. Your photos never leave your device.

The site source does not include analytics scripts, tracking pixels, or a site contact form. GitHub hosts this website and may process request data under its own policies.

Your Photos

The Fix My Photo Dates desktop application:

  • Processes photos entirely on your computer
  • Never sends photos to remote servers
  • Never stores photos in the cloud
  • Records original filesystem timestamps and EXIF date values in a local rollback manifest, so changes can be undone
  • Optionally saves a full copy of each original file before changing it, when you turn on that setting
  • Provides rollback for values recorded by the app; keep independent backups of important photos

Website

This website does not include:

  • Include Google Analytics or other analytics scripts
  • Set site tracking cookies
  • Include a form that collects personal information
  • Include tracking pixels or beacons

Third-Party Services

The website loads typography from Google Fonts. A browser requesting these fonts connects to Google's servers and is subject to Google's privacy policy. GitHub Pages hosts the site. Microsoft Store links leave this website.

Security

We take security seriously:

  • The desktop application never requires an internet connection
  • No credentials are stored or transmitted
  • All metadata changes are logged locally

Changes to This Policy

We may update this privacy policy from time to time by changing the "Last Updated" date above.

Contact Us

If you have questions about this privacy policy, use the contact or support link on the Microsoft Store listing.
